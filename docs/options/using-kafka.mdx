## Features

[Kafka](http://kafka.apache.org/) is a popular publish-subscribe messaging system. JHipster has an optional support for Kafka, that will:

- Configure [Spring Cloud Stream](https://spring.io/projects/spring-cloud-stream) with its Kafka binder.
- Add the necessary configuration in the `application-*.yml`
- Generate a Docker Compose configuration file, so Kafka is usable by typing 
  ```shell
  npm run docker:kafka:up
  ```


## Prerequisite

Generate a new application and make sure to select `Apache Kafka as asynchronous messages broker` when prompted for technologies you would like to use. A Docker Compose configuration file is generated and you can start Kafka with the command:

```shell
npm run docker:kafka:up
```


## Consumer and Producer

A consumer (`broker/KafkaConsumer` class) is running and can be adapted to your needs.

A producer (`broker/KafkaProducer` class) is also available, and messages can be published through a REST endpoint (`<appName>KafkaResource` class).


## Running the app

Allow access to the endpoint in `SecurityConfiguration.java`:

```java
.requestMatchers("/api/<appName>-kafka/publish").permitAll()
```

(use `.pathMatchers(...)` in a reactive application)

If you invoke the endpoint with a `POST` request, you should see the message logged to the console:

```shell
curl -X POST 'http://localhost:8080/api/<appName>-kafka/publish?message=...'
```
