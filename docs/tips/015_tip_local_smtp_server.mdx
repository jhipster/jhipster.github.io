The project [maildev/maildev](https://github.com/maildev/maildev) is a simple way to test your project's generated emails during development with an easy to use web interface.

To start locally the SMTP server with Docker:

```shell
docker container run -d -p 1080:1080 -p 25:1025 maildev/maildev
```

MailDev listens for SMTP on port 1025 and serves its web interface on port 1080. The command above publishes the SMTP port as port 25, which is what `spring.mail.port` is set to in the generated `application-dev.yml`. The web interface is available at http://localhost:1080.
